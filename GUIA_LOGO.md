# 📸 GUÍA PARA EL LOGO DE TOTAL LIVING

## Formatos Recomendados

Para obtener la mejor calidad visual sin pixelación, te recomiendo los siguientes formatos:

### **Opción 1: SVG (RECOMENDADO)** ⭐
- **Formato:** `.svg`
- **Ventajas:**
  - Escalable sin pérdida de calidad
  - Tamaño de archivo pequeño
  - Se ve perfecto en cualquier tamaño
  - Ideal para web

### **Opción 2: PNG de Alta Resolución**
- **Formato:** `.png`
- **Resolución mínima:** 2000x2000 píxeles (o más)
- **Ventajas:**
  - Buena calidad
  - Compatible con todos los navegadores
  - Fondo transparente recomendado

### **Opción 3: PDF Vectorial**
- **Formato:** `.pdf`
- **Ventajas:**
  - Escalable
  - Puede contener vectores

---

## Especificaciones Técnicas

### Para el Header/Navbar:
- **Tamaño recomendado:** 200-250px de ancho
- **Formato preferido:** SVG o PNG con fondo transparente
- **Altura:** Proporcional (máximo 60px de altura)

### Para Favicon:
- **Tamaño:** 32x32px o 64x64px
- **Formato:** `.ico` o `.png`
- **Versión simplificada del logo**

### Variantes Necesarias:

1. **Logo Principal** (color completo)
   - Con todos los colores de la marca
   - Para uso general

2. **Logo Monocromo** (opcional pero recomendado)
   - Versión en un solo color (#F2ECE0 - Creamy Beige)
   - Para usar sobre fondos oscuros

3. **Logo Horizontal**
   - Logo con texto al lado
   - Para header

4. **Logo Vertical** (opcional)
   - Logo con texto abajo
   - Para footer o espacios verticales

## Ubicación en el Proyecto

Una vez que me envíes el logo, lo colocaré en:
- `static/images/logo.svg` (o .png)
- `static/images/logo-white.svg` (versión para navbar)
- `static/images/favicon.ico` (favicon)

**El formato SVG es el mejor** porque:
- ✅ No se pixelea nunca
- ✅ Se adapta a cualquier tamaño
- ✅ Carga más rápido
- ✅ Se ve perfecto en todas las pantallas
